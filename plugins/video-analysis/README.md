# 영상 분석

YouTube 영상이나 로컬 동영상의 내용을 요약하고, 질문에 답할 때 근거가 된 장면의 재생 시각을 알려 줍니다.
예를 들어 “새로고침한 뒤에도 입력한 값이 남아 있는 장면이 어디야?”라고 물을 수 있습니다.

## 어떻게 분석하나요?

자막, Whisper가 받아쓴 말, OCR이 읽은 화면 글자를 재생 시각에 맞춰 봅니다.
화면 아래 같은 자리에 발표자의 말에 맞춰 글자가 바뀐다면 화면에 입힌 자막일 수 있습니다.
터미널에 표시된 값이 바뀌었는지 확인할 때는 해당 시각 전후의 원본 프레임을 비교합니다.

여행 영상에서 식당에 들렀는지 물었는데 간판만 보이면, 답에도 간판을 확인했다고 적습니다.
입장 장면이나 방문했다는 발언을 찾으면 그 구간을 함께 제시합니다.
설명란에서만 소개한 곳은 설명란을 출처로 밝힙니다.

## 어떤 결과를 받나요?

YouTube 영상은 근거가 된 장면부터 열리는 링크를, 로컬 파일은 플레이어에서 찾아볼 재생 시각을 제공합니다.
다른 작업에 결과를 넘길 때는 같은 영상의 `evidence_timeline.json`을 공유합니다.
이 파일에는 자막·음성 전사·OCR에서 읽은 글과 각각의 출처, 재생 시각이 들어 있습니다.
에이전트는 질문별 결론과 직접 확인한 장면, 확인하지 못한 점을 작업별 `analysis.json`에 기록합니다.
