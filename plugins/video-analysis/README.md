# 영상 분석

YouTube 영상이나 로컬 동영상에 대해 질문하면, 해당 장면에서 확인한 내용과 재생 시각을 함께 알려줍니다.
영상 전체를 요약하거나 “새로고침 버그가 실제로 고쳐진 장면이 어디야?”처럼 한 가지 행동을 확인할 수 있습니다.

## 어떻게 분석하나요?

먼저 제목과 설명란에서 주제를 파악하고, 자막과 Whisper가 받아쓴 말, OCR이 읽은 화면 글자를 같은 시간축에 놓습니다.
한 영상에서도 화면 아래에는 발표 자막이, 바로 옆에는 터미널의 상태 표시가 뜰 수 있습니다.
글자의 위치와 내용이 앞뒤 장면에서 어떻게 바뀌는지, 발표자의 말과 맞는지를 함께 봅니다.

이 자료로 답할 수 있으면 근거가 된 구간을 알려줍니다.
예를 들어 여행 영상에서 식당 간판이 읽혔는데 실제로 방문했는지가 질문이라면, 에이전트가 해당 시각과 앞뒤의 원본 이미지를 직접 봅니다.
가게에 들어가는 모습이 확인되면 그 장면을 근거로 제시하고, 간판만 보이면 어디까지 확인했는지 답에 적습니다.
설명란에서만 소개한 곳은 장면 시각을 비워 둡니다.

## 어떤 결과를 받나요?

대화에서는 요약이나 질문에 대한 답과 해당 시각부터 열리는 영상 링크를 받습니다.
다른 작업에서 재사용할 때는 `evidence_timeline.json`에 출처와 시각별 원문이, `analysis.json`에 구간별 해석과 직접 확인한 장면, 미확인 사항이 담깁니다.
그래서 같은 영상을 다시 내려받지 않고도 한 작업은 장소를 찾고 다른 작업은 시연을 요약할 수 있습니다.
